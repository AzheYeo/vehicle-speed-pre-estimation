# 证据模型与失败模式

## 证据层

| 层级 | 能支持 | 不能单独证明 |
|---|---|---|
| 原始证据 | 文件身份、运行环境和复现条件 | 视频内容真实性 |
| 编码时间 | 成品时间戳、GOP和packet规律 | 画面内容等间隔采样 |
| 画面内容 | 重复、冻结、突变或更新节律 | 异常产生的具体软件和环节 |
| OSD时间 | 画面内时间文字的相对规律 | 绝对时间真实性或原始采样帧率 |
| 目标运动 | 指定目标的图像平面运动连续性 | 实际物理车速 |
| 综合推断 | 多层证据共同支持的解释 | 缺少生成链时的唯一原因认定 |

证据冲突时并列报告，不以某一层覆盖其他层。例如PTS连续与运动倍率周期异常可以同时成立。

## 位移突增

可能原因：内容跨越多个原始采样间隔、PTS长间隔、跟踪漂移、遮挡、目标切换、透视快速变化、真实加速/转向或画面突变。

复核：检查前后恢复形态、多特征点方向、正反向误差、重叠车辆同帧结果、PTS差、OSD、哈希/差分和车辆物理状态。

允许表述：“该帧对为运动不连续候选，支持内容跨度增加假设。”不得直接写“该帧被删除”。

## 位移接近零

可能原因：冻结或重复帧、车辆真实停止、纹理不足、LK失败、检测框量化或遮挡。

复核：检查全帧/ROI哈希、差分、多目标是否同步、有效点和误差。哈希相同是重复强证据；哈希不同不等于存在有效运动。

## 周期性候选

周期性只描述节律。先逐帧定位候选，再用候选间隔、OSD完整秒计数、自相关或FFT辅助描述。不得从FFT峰值直接反推删帧事实。

若完整OSD秒内候选次数稳定、候选倍率接近整数跨度、候选间隔与目标帧率模型一致，可表述为“支持周期性内容跨度增加模型”。

## 跟踪失败

信号：有效点骤降、正反向误差升高、方向分散、框混入邻车、倍率异常不在其他目标复现。

处理：终止片段、回退到最后合格帧、选择新目标或改用轮廓/人工测点；不得插值补齐。

## 遮挡与交接

遮挡前后身份不明确时不得强接轨迹。交接区用不同车辆分别测量；原始位移不合并，只比较格式化倍率。交接一致性只能增强候选可信度，不能单独确定原因。

## 透视与真实运动变化

车辆接近摄像机时像素位移和尺寸通常增大，远离时通常减小。局部稳健基线应跟随长期趋势。急刹、加速、转向或碰撞可造成真实突变；无法排除时降低结论强度或标为不可评价。

## 推荐结论层级

1. 观察事实：可直接追溯的数据。
2. 异常候选：超过本案阈值且质量合格。
3. 支持的假设：多层证据一致。
4. 仍存的替代解释：尚未排除。
5. 不能推出的结论：实际车速、具体软件或法律意义上的处理事实。
