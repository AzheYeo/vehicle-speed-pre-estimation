## 1. 帧对与选车

把待检区间转换为全部严格相邻帧对：

```text
frame_start→frame_start+1
...
frame_end-1→frame_end
```

选择目标的优先级：

1. 完整覆盖是硬约束。
2. 在完整覆盖方案中最小化车辆数量。
3. 车辆数量相同时，优先像素面积大、纹理清楚、遮挡少、身份稳定且连续可见的组合。

先验证单车，再依次验证两车及更多车辆。不能为了形式增加近、中、远目标；也不能为了减少车辆而使用低质量片段。

## 2. 实际片段和重叠交接

车辆片段起止帧由目标实际可评价范围决定，不按用户时间区间或交接点做互斥partition。

终止条件：

- 出画或紧贴边界导致车身不足；
- 被遮挡或目标框混入其他车辆；
- 身份无法保持；
- 有效特征点、方向一致性或正反向误差不合格；
- 急转、急刹、碰撞或明显物理加速使其不适合作为采样参照。

交接规则：

- 交接帧必须共享，不得漏掉帧对；
- 条件允许时扩宽相邻车辆的实际片段，保留2至3个重叠帧对；
- 重叠帧对对每辆车分别计算，禁止混合特征点；
- 重叠区比较格式化倍率是否在同一到达帧同步异常；
- 没有合格车辆的帧对标记 `not_evaluable`，不得插值。

## 3. 单车测量

对每个严格相邻帧对：

1. 在前帧紧致车辆框或掩膜内检测车身特征点。
2. 使用LK正向跟踪到后一帧，再反向回验。
3. 剔除反向误差超限、落出后一帧目标框、方向异常或明显属于背景/邻车的点。
4. 计算每个合格点的 `dx`、`dy`、位移和沿车辆主运动方向的投影。
5. 使用投影位移中位数作为该帧对测量值。
6. 保存原始点数、有效点数、误差、方向一致性、ROI和目标编号。

推荐起始门槛（按视频校准）：

- 目标框面积约不低于1000 px²；
- 短边不低于20 px；
- 有效特征点不少于15个；
- 正反向中位误差不高于0.8 px。

面积只作初筛。禁止跨帧轨迹冒充相邻帧位移、丢点后把新点接回旧轨迹、用平滑值替代原始值，或把固定大ROI内多车运动当成单车位移。

## 4. 局部基线与候选

每辆车单独建立能跟随长期透视趋势的局部稳健基线：

```text
motion_ratio_i = projected_displacement_i / local_expected_displacement_i
```

候选至少满足：

- 倍率超过本案阈值；
- 有效点和误差合格；
- 多数点同步变化且方向与前后帧可解释；
- 呈现“小位移→较大位移→恢复”的局部形态；
- 不是遮挡、目标切换、框漂移或可解释的物理运动变化。

若疑似跨越两个原始间隔，倍率通常接近2，但不得机械要求精确等于2。

每个候选保存：目标、片段、起止帧、到达帧相对时间和OSD、投影位移、局部基线、倍率、有效点、误差、方向一致性和证据图片。

## 5. 重叠共识

每辆车原始曲线分别绘制，不跨车连线或平均。

重叠帧对：

- 保留每辆车的独立原始记录；
- 比较无量纲倍率，而非原始 `dx/dy`；
- 多车在同一到达帧出现相近倍率，可增强该候选对目标选择的稳健性；
- 结果冲突时检查各车质量、物理运动和遮挡，不强行形成共识。

需要一行一个唯一到达帧的汇总表时，默认以重叠车辆倍率中位数作为共识倍率；`dx/dy`取质量最优的代表车辆并明确标注。该汇总不替代独立原始记录。

综合倍率曲线：

- 横轴为全局到达帧号；
- 不同车辆使用不同颜色；
- 交接处断线并标注重叠区；
- 正常基线为1.0；
- 候选标红，只标到达帧号。

## 6. OSD倍率计数

先校准本案倍率分级。例如：

```text
ratio < 1.6       → inferred_step = 1
1.6 ≤ ratio < 2.6 → inferred_step = 2
2.6 ≤ ratio < 3.6 → inferred_step = 3
```

后续以相同宽度递增。阈值必须保存为配置并说明依据。

对每个完整OSD秒内的唯一帧对求和：

```text
inferred_original_intervals = Σ inferred_step
```

人工复核表逐行保存同一显示OSD秒内的运行累计值：

```text
osd_running_inferred_count_i = Σ inferred_step_j
```

求和范围为当前显示OSD秒内从第一条唯一帧对到当前行；OSD秒变化时重新累计。该字段可兼容命名为 `OSD秒间帧数`，但必须在数据说明中明确其为倍率推定累计值。共识倍率达到候选阈值且质量合格的行增加 `异常标记=异常`，用于人工复核。

同时报告成品帧间隔数、候选次数、推定原始帧间隔数和候选间距。由于OSD边界与帧相位可能错开，各完整秒可在目标值两侧摆动；优先检查多秒平均和稳定节律。首尾边界秒不用于模型结论。

## 7. 验收清单

- [ ] 全部唯一相邻帧对已覆盖或标为不可评价。
- [ ] 车辆数是完整覆盖下的最少方案。
- [ ] 片段按实际质量范围展开，不是互斥时间partition。
- [ ] 每处可行交接保留2至3个重叠帧对。
- [ ] 每辆车身份、范围、ROI、质量和终止原因明确。
- [ ] 每辆车单独建立局部基线。
- [ ] 原始 `dx/dy` 未跨车连接或平均。
- [ ] 重叠共识只使用格式化倍率，并保留独立记录。
- [ ] 候选可追溯到具体到达帧和证据图。
- [ ] OSD完整秒、边界秒和倍率计数口径明确。
- [ ] 人工复核精简表的OSD秒内累计值可由共识倍率分级逐行复算，异常标记与候选阈值一致。
- [ ] 结论区分成品编码、内容采样模型和实际物理车速。
