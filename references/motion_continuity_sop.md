## 1. 覆盖与选车

把待检区间转换为相邻帧对集合：

```text
frame_start→frame_start+1
...
frame_end-1→frame_end
```

选车采用分层优化：

1. 完整覆盖是硬约束。
2. 在完整覆盖方案中最小化车辆数量。
3. 车辆数量相同时，最大化以下质量：
   - 可见像素面积；
   - 有效车身纹理；
   - 连续可见帧数；
   - 与其他车辆的分离程度；
   - 特征点数和跟踪稳定性。

必须先验证单车方案。单车因出画、遮挡或质量不足不能覆盖时，再验证两车方案；两车已覆盖时不得增加第三辆车。

车辆片段起止帧是质量变化产生的结果，不预设固定秒数。

## 2. 遮挡和交接

以下任一情况触发当前车辆终止：

- 目标出画或紧贴边界导致车身区域不足；
- 被另一车辆或固定物遮挡；
- 目标框混入其他运动目标；
- 有效特征点少于门槛；
- 正向—反向误差超限；
- 多数特征点方向不再符合该车整体运动；
- 车辆急转、急刹或物理加速使其不适合作为时间采样参照。

交接规则：

- A车结束帧同时作为B车起始帧；
- A负责结束帧之前的最后一个帧对，B负责从交接帧开始的下一个帧对；
- 条件允许时保留2至3个重叠帧对分别分析，用于核对两车是否在相同全局帧号检出异常；
- 重叠分析仍分别计算，不混合特征点；
- 无合格车辆的帧对标记不可评价。

## 3. 单车逐帧测量

对每一组严格相邻帧：

1. 在前帧紧致车辆框或掩膜内检测车身角点。
2. 使用LK光流跟踪到后一帧。
3. 反向跟踪回前帧。
4. 剔除反向误差超限、落出后一帧目标框或方向异常的点。
5. 计算每个点的 `dx`、`dy`、位移及沿车辆主运动方向的投影。
6. 使用投影位移中位数作为该帧对测量值。
7. 保存原始值、有效点数、中位反向误差、目标框和目标编号。

禁止：

- 把 `frame N→frame N+2` 的位移写成单帧位移；
- 丢点后把新检测点接回旧轨迹；
- 用平滑值替代原始相邻帧测量；
- 把固定大ROI内所有车辆的帧差当作某一车辆位移。

## 4. 候选判断

车辆驶近或远离会形成长期透视趋势。每辆车分别使用局部稳健基线：

```text
ratio_i = displacement_i / local_expected_i
```

候选至少同时满足：

- 位移倍率超过本案经正常区间校准的阈值；
- 有效特征点达到门槛；
- 多数特征点同时变化；
- 方向与前后帧一致；
- 不是遮挡、车辆物理加减速、目标切换或框漂移。

重点识别：

```text
连续小位移 → 单次较大位移 → 恢复小位移
```

若疑似删1帧，较大位移通常接近局部正常位移的2倍。候选必须记录：

- 指定车辆和片段编号；
- 起始帧、到达帧；
- 到达帧相对时间和OSD秒；
- 实测位移、局部正常位移、倍率；
- 有效点数、误差和方向一致性。

## 5. 多车综合曲线

原始曲线按车辆分别绘制，不跨车连线。

综合曲线只使用各车的格式化倍率：

```text
normalized_i = displacement_i / local_expected_i
```

要求：

- 横轴使用全局到达帧号；
- 车辆交接处断线；
- 使用不同颜色区分车辆；
- 标出交接帧；
- 候选点标红；
- 点标签只写到达帧号，不加前导零；
- 明细表保留完整帧对。

FFT或自相关只能用于观察已定位候选的重复间隔，不作为候选产生的唯一依据。
