# 运动连续性分析方法

## 帧对与目标

把用户区间转换为全部严格相邻帧对：

```text
frame_start → frame_start+1
...
frame_end-1 → frame_end
```

异常标签使用发生变化后的到达帧号。覆盖全部指定帧对；没有可靠目标的帧对标记为不可评价，不要插值。

用户已指定车辆、参照物或ROI时必须使用该目标。用户未指定时，在完整覆盖前提下使用最少目标；目标数量相同时优先尺寸大、纹理清楚、遮挡少、身份稳定且连续可见者。

目标交接处条件允许时保留2至3个重叠帧对。不同目标分别测量，不混合特征点，不连接或平均原始 `dx`、`dy`。

## 方法选择

| 画面条件 | 优先方法 | 主要质量指标 |
|---|---|---|
| 固定机位、车辆纹理清楚 | 紧致ROI内稀疏LK光流 | 有效点数、正反向误差、方向一致性 |
| 纹理不足但轮廓清楚 | 轮廓中心、检测框或人工边界 | 轮廓稳定性、框抖动、遮挡 |
| 目标很小 | 人工测点或标记不可评价 | 尺寸、可重复性 |
| 移动或抖动机位 | 背景仿射补偿后测目标 | 背景内点率、残差 |
| 夜间、车灯或反光 | 人工ROI并结合多证据 | 饱和、曝光变化、跟踪质量 |
| 已有人工锚点 | 锚点约束动态ROI | 身份、框内单一目标 |

优先采用满足质量要求的最简单方法。人工锚点只约束ROI，不得用锚点插值替代实际相邻帧位移。

## LK相邻帧测量

1. 在前帧紧致目标框或掩膜内检测车身特征点。
2. 正向跟踪到后一帧，再反向回验。
3. 剔除反向误差超限、落出目标框、方向异常或属于背景与邻车的点。
4. 计算各点 `dx`、`dy`、欧氏位移和沿目标主运动方向的投影位移。
5. 使用合格点投影位移中位数作为该帧对的测量值。
6. 保存有效特征点数、正反向误差和目标编号。

推荐起始门槛仅供本视频校准：目标框面积约不低于1000 px²、短边不低于20 px、有效点不少于15个、正反向中位误差不高于0.8 px。不要把这些经验门槛写成行业标准。

目标出画、遮挡、框混入其他目标、身份不明、有效点不足、误差超限，或发生明显碰撞、急刹、急转时，终止当前片段或降低结论强度。

## 局部基线与倍率

每个目标独立建立能够跟随长期透视趋势的局部稳健基线：

```text
运动不连续倍率 = 当前投影位移 / 局部正常投影位移
```

候选应同时满足：倍率超过本视频阈值，点数和误差合格，多数点同步变化，局部形态可解释，且没有被遮挡、目标切换、框漂移或明确真实运动变化更好地解释。

疑似跨越两个原始间隔时，倍率通常接近2，但不机械要求精确等于2。

## 多目标复核

重叠帧对保留各目标独立结果，只比较无量纲倍率。多目标在同一到达帧出现相近倍率可以增强结论；结果冲突时检查质量和物理状态，不强行形成共识。

CSV只能保存一个倍率时，选择质量最好的代表目标；在 `采用目标` 中写明来源。不要让代表目标的原始位移与其他目标的共识倍率混在同一计算链中。

## 替代解释

每个候选至少复核：

- 相邻PTS差是否同步变化；
- 目标是否被遮挡、切换或出画；
- 特征点数和正反向误差是否恶化；
- 透视尺度、姿态或反光是否快速变化；
- 车辆是否真实加速、制动、转向或碰撞；
- 多目标是否在同一到达帧同步异常；
- 是否存在重复、冻结或全局画面突变。

PTS均匀只说明成品时间戳规律，不证明画面内容等间隔更新。运动倍率异常也不能单独证明某帧被删除。
