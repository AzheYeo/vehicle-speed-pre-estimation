# 基础输出数据契约

## Info摘要

把以下字段置于 `info.txt` 最前面，保持适合直接复制：

```text
文件名称：
SHA-256：
MD5：
文件大小：<可读值>（<bytes> bytes）
播放时长：<hhmmss>（<seconds> s）
分辨率：<width>×<height>
帧频率：
```

同时给出 `r_frame_rate` 和 `avg_frame_rate`。二者一致时可写为：

```text
帧频率：25 fps（r_frame_rate=25/1，avg_frame_rate=25/1）
```

二者不一致时并列报告，不擅自选取一个作为唯一真实帧率。

## Info OSD跳秒到达帧

紧接摘要信息，列出目标区间内全部可确认的OSD秒值变化。到达帧是新OSD秒值出现的第一帧，格式统一为：

```text
OSD跳秒到达帧：
08:03:09 → 08:03:10：帧序号1523，PTS时间_s=68.120000
08:03:10 → 08:03:11：帧序号1548，PTS时间_s=69.120000
```

保留OSD时间的八位 `hh:mm:ss` 格式和前导零。OCR无法可靠确认的跳秒不要猜测，在该部分注明无法确认的范围。此部分只记录画面OSD变化，不据此认定跳帧。

## Info容器信息

保留：封装格式、格式长名称、容器起始时间、容器时长、容器总码率、流数量、视频流数量、音频流数量、容器标签和 `creation_time`。缺失字段写“未提供”。把 `creation_time` 明确作为容器元数据，不认定为真实拍摄时间。

## Info视频流信息

保留：视频流序号、编码格式、编码格式长名称、profile、level、分辨率、像素格式、扫描方式、显示宽高比、像素宽高比、旋转信息、`time_base`、`r_frame_rate`、`avg_frame_rate`、`start_pts`、`start_time`、`duration_ts`、`duration`、`bit_rate`和声明帧数。

## Info复现信息

保留：分析工具及版本、FFmpeg版本、FFprobe版本、OCR工具及版本、生成时间、帧序号定义、播放器时间定义、OSD识别区域、OSD识别方式、实际执行命令、CSV文件名称和帧图片目录。

不要在info正文中重复记录用户指定时间区间；区间只写入info文件名、CSV文件名和帧图片目录名称。

## 字段语义

- `帧序号`：全视频首个实际可显示帧为1，按显示顺序递增，是帧图和数据行的UID。
- `PTS时间_s`：FFprobe读取的原始 `pts_time`。
- `相邻PTS差_s`：当前显示帧PTS减上一显示帧PTS；全视频首帧留空。小于0表示非单调，等于0表示重复时间戳，间隔变化只作为进一步复核线索。
- `播放器时间_s`：当前帧PTS时间减全视频首个实际可显示帧PTS时间。
- `OSD时间`：标准化为八位 `hh:mm:ss`，小时、分钟、秒均保留两位和前导零，例如 `08:03:09`；不保存日期。
- `OSD秒间帧序号`：成品视频中同一显示OSD秒内的实际显示顺序，从1计数。
- `修正后OSD秒间帧序号`：第一阶段等于原始序号；第二阶段按推定帧间隔增量累计。
- `帧类型`：I、P或B。
- `运动异常备注`：第一阶段留空；第二阶段只在异常到达帧填写，正常帧留空。
- `推定帧间隔增量`：第一阶段为1；第二阶段按运动倍率和质量复核确定。
- `GOP编号`和 `GOP内帧序号`：派生字段，必须在复现信息中说明算法。
- `备注`：记录OCR失败、DTS缺失、解码错误或边界秒不完整等非运动异常事项。

不要用小数格式化值覆盖整数PTS、DTS或duration。无法读取的字段保留空值或 `N/A`。
